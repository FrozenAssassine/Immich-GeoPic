# GeoPic

## This project is a work in progress. Many features need to be improved. You're welcome to contribute.

## Requirements
- Node.js installation
- Installation of a package manager (npm/yarn/pnpm/...)

## Getting Started

First, create a folder "public" and paste all jpg images in there.

Second, run install dependencies:

```bash
npm install
```

Third, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Roadmap/Future features:
- Load images from other directories
- Load other file types
- Add "Remove coordinates" functionality
- Improve marker updates after fixing multiple markers at once
